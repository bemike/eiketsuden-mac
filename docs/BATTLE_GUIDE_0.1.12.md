# Mac 0.1.12：本关要点

出战准备左侧菜单，在「部队编成」下新增「本关要点」。读取当前即将出征的关卡，原版边框内显示四组提示：

- **单挑与会面**：参与武将、相邻条件、升级和撤退结果；我方单挑失败会特别标出。战后加入的武将列在这一组。
- **宝物与兵书**：地图宝物格、实际击退掉落和战后剧情奖励。敌军仅携带、没有掉落定义的装备不列为奖励。
- **物品与军资金**：消耗品、宝箱资金、过关资金以及有条件的剧情奖励。
- **兵种转换**：本关可获得、商店可买或队伍已持有的晋升和转职道具，注明转换兵种。兵书装备与转职道具分别列示。

坐标按地图左上角为原点，第一格为「列1、行1」。宝物格需停留领取。单挑接触依游戏规则为上下左右相邻；此处与道具的周围八格使用范围不同。

长内容自动换行分页，分页继续时重复栏目标题。鼠标点击上一页/下一页、方向键、滚轮均可翻页，Esc 或右下角返回可回营地。查看不会修改游戏状态、消耗物品、提前触发剧情或更改存档格式。旧存档可继续使用。

## 资料和数据范围

用户指定参考：[三国志英杰传单挑、宝物列表](https://www.cnblogs.com/lykouyi/p/5688506.html)（cnblogs，lykouyi）。此网页用于确定内容类别及核对常见事件，游戏未复制其完整表格或攻略正文。

显示内容从本项目实际运行的战斗定义、物品规则和剧情脚本整理：当前包有 70 份用于战役的战斗定义，包括 64 份章节战斗及后续补齐的分支/连战变体。按关卡 ID 区分同名战斗，随转换包更新；无需联网。

战后查询跟随剧情跳转、选项和标记赋值，止于下一场战斗的准备营地。对同一奖励只保留较短的选择路径，避免重复问答产生大量重复提示。战斗期间可能改变的剧情条件标为有条件奖励，不能视为保证获得。需要接触收服的人物，仍须实际完成其对应剧情。提示以当前引擎的数据为准，并非对原版所有隐藏内容已逐项验证的承诺。

例如徐州第一战可看到关羽与于禁接触的单挑，以及战后选择张飞建议路线获得雌雄双剑的提示；广川、北海分别显示关羽与逢纪、赵云与管亥的单挑。麦城战后联盟奖励与后续关卡宝物不会混为一关。
