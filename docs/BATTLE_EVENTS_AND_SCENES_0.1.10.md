# 0.1.10：战斗事件与过场画面修复

广川之战原版包含关羽接触逢纪后的单挑。此前转换包只有开场事件，单挑与宝物在原版的下一个脚本块里，被错误地当作战后文字剧情。新版把两个块连接为同一场战斗，保留开场、单挑、两处宝物、战后奖励与剧情顺序。

同时修复：

- 许昌第二、第三场以 `battle_end next_map=0x30xx` 切换地图的战斗。该指令在开战前表示换地图，不能当成过场结束或忽略；两场现在正常包含战斗、回合事件与单挑。
- 脚本内特定条件下出现的匿名武将。原版 BAKDATA 372 有独立属性和头像，不能因没有基础包的对应武将而丢弃。条件援军采用独立出场分组，避免被同一记录里的普通援军提前带出。
- 原版 SMAP 城镇与 MMAP 大地图背景。此前只导出 PMAP 室内场景，其他场景在原生界面中显示成黑底。新版使用各自的原版地图、图块和调色板。序章与第一章共用第一张大地图，后续章节使用各自地图；大地图按刘备所在位置截取视区。
- 跨剧情块沿用上一幕的背景。背景随战役状态保存；过场快速存档的旧指令位置在载入时调整，只恢复显示，不重放钱财、入队等副作用。战斗叠加剧情继续显示战场。
- 豆、酒等直接给己方使用的道具支持自身和周围八格，修正目标列表与实际使用判定。两格外或敌方仍不可使用；公用道具和武将随身道具采用相同规则。
- 新恢复对白所需的「塌」字补入两套字体。

## 验证范围

读取中文 DOS 版的五组 SNR 文件，统计全部 432 条战斗触发记录，其中 99 条接触触发记录。每条均能归入相应战斗，不再存在独立事件块被当作纯文字剧情的情况。转换包的路线分支使接触事件总数多于原始记录数。

通过引擎实际载入转换资源的检查：广川开始不提前单挑；关羽合法移动到逢纪相邻格时触发一次；关羽升一级、逢纪退场；模拟旧版只有一个事件标记的存档能够触发新增事件；再次载入后不重复。校验许昌两场及匿名武将接触事件已写入。

自动化回归覆盖分块战斗、开战前换地图、条件援军、城镇与大地图背景、地图边界裁切、跨块背景、旧过场存档的位置与幂等恢复。全部 763 项 workspace 测试与资源引用校验通过，打包字体检查不允许缺字或空轮廓。

另外使用隔离存档在打包应用中实际移动关羽，确认单挑对白与骑马演出出现；载入第一章路线选择过场，确认大地图显示。

这是脚本全量检查加重点运行验证，没有宣称逐关人工通关。地图的装饰物、城镇逐帧行走和大地图军旗仍未完整重建。

## 自行复查

工具只读取明确指定的资源目录；所有测试存档写入明确指定的新目录。

```sh
cargo run --release -p hero-import --example audit_scenarios -- /path/to/DOS /path/to/private-audit.json
cargo run --release -p hero-tools --example verify_original_events -- /path/to/converted-pack /path/to/isolated-test-saves
cargo test --workspace
```

审计 JSON 含原版游戏脚本，应按原版素材的发布范围保存。
