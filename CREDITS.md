# Credits

Eiketsuden Reloaded is an original reimplementation. **No material from KOEI / KOEI TECMO — no
graphics, music, sound, text, data or code of the original game — is included in this repository
or in its releases.** The base pack (`data/base`) is built only from the openly licensed sources
below and from art made for this project.

The engine code is licensed under GPL-3.0-or-later. Media files keep the licence of their source,
listed here. Every file under `data/base/gfx`, `data/base/sfx` and `data/base/fonts` is generated by
the asset pipeline in [`tools/assets/`](tools/assets/README.md), which pins each source archive by URL
and SHA-256 (`tools/assets/sources.toml`) so the pack can be rebuilt byte for byte.

## Art made for this project

The pixel art drawn for Eiketsuden Reloaded — the sprites defined as text in
`tools/assets/art.py` (weather, stat and item icons, village huts, houses, tents, watchtower,
storehouses, city gate, the horse's back view, chariot parts, saddle cloths, pennants, drum, rice
bales) and the walls, palisades, bridges and paving generated by `tools/assets/build_terrain.py` —
is dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
It uses the Ninja Adventure colour palette.
